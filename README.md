# Пульс — серверный вариант 0.1

Отдельная монорепа для развёртывания: Node.js API + PostgreSQL, React-анкета `/mood`, публичный дашборд `/dash`. Оба экрана без авторизации.

Готовая статическая сборка находится в `web/`. Конфигурация API — `web/runtime-config.js`.

Инструкция по портам, Env, PostgreSQL, томам, резервным копиям и загрузке tar: [DEPLOY.md](DEPLOY.md). Фактическая готовность поставки: [STATUS.md](STATUS.md).

Для разработки: Node.js 22+, `npm ci`, `npm test`, `npm run build`. Для запуска задать DATABASE_URL и выполнить `npm start`. Node одновременно отдаёт API и статическую сборку на порту 8080.

Это новая версия сбора данных, прежние Excel и архив не импортируются автоматически. Дашборд первой итерации содержит общую и недельную сводки; полный набор возможностей исходного сайта ещё не перенесён.
